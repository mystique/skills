# Agent Skills

A collection of reusable agent skills for common software development workflows.

## Available Skills

| Skill | Description |
| --- | --- |
| [`git-commit`](skills/git-commit/SKILL.md) | Create clear, well-scoped, and verifiable Git commits. |

## Installation

Install all available skills:

```bash
npx skills@latest add <owner>/<repo>
```

Install a specific skill:

```bash
npx skills@latest add <owner>/<repo>@git-commit
```

Replace `<owner>/<repo>` with the GitHub repository path.
